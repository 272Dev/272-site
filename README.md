# ⛧ 272 ⛧

Site do servidor 272.

## Como usar

1. Ativa o **GitHub Pages** no repositório
2. Vai em **Settings > Pages**
3. Seleciona a branch `main` e pasta `/ (root)`
4. O site vai ficar online em `https://seuusuario.github.io/272-site/`

## Estrutura

```
272-site/
├── index.html   ← site completo (arquivo único)
└── README.md
```
